# Golden Paths

Use a Golden Path only for a new product or when the repository lacks a nearby
working pattern. Select the closest product archetype:

- [Web application](web-application.md)
- [Internal tool](internal-tool.md)
- [Content or commerce site](content-commerce.md)
- [Mobile H5 or mini app](mobile-h5-miniapp.md)
- [API service](api-service.md)
- [AI application](ai-application.md)

A Golden Path supplies default boundaries and first-slice order, not a mandatory
framework. Prefer an organization standard or user-provided stack. When no stack
evidence exists and the choice will be expensive to reverse, recommend one boring,
cohesive stack and ask once before scaffolding broadly.
